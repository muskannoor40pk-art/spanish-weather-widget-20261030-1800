## Overview
The Weather Widget is a lightweight, single-file dashboard providing real-time weather insights. Built specifically for the Latin American and Spanish markets, this tool emphasizes clarity, local cultural formatting, and ease of use. It is perfect for developers looking for a clean UI implementation without the complexity of backend API management.

## Features
*   **City Search:** Intuitive search bar to find weather data for any location.
*   **Current Conditions:** Detailed card displaying temperature, humidity, and wind speed.
*   **Hourly Forecast:** Visual timeline for the next 24 hours.
*   **5-Day Forecast:** Planning-ready outlook for the upcoming week.
*   **Zero-Config:** Uses realistic built-in demo data—no API keys required.
*   **Mobile-First:** Fully responsive layout using modern CSS Grid and Flexbox.

## Localization Notes
*   **Language:** Fully localized into Spanish (es-ES/es-LATAM).
*   **Formats:** Uses metric units (Celsius) and Spanish date/time formatting (DD/MM/YYYY).
*   **Accessibility:** Optimized for LTR (Left-to-Right) reading flows standard in Spanish typography.

## Tech Stack
*   **HTML5:** Semantic markup for better accessibility.
*   **CSS3:** Modern layout techniques (Flexbox, Grid) and custom properties.
*   **Vanilla JavaScript:** Efficient DOM manipulation without external dependencies.
*   **GitHub Pages:** Seamless deployment and hosting.
